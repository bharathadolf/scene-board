# Who decides what: the board and the applications

One rule holds the pipeline together, and it is enforced in code in two places
(`src/shotspec.js` for the board, `pipeline/dcc_bridge.py` for everything else;
a test keeps the two lists identical):

> **The board says what a shot is. An application says what it made of it.**

## What flows down — the shotspec

Generated by the board (the *Previz* section of a scene, a sequence or the
board) or by `node scripts/shotspec.js`. One JSON document, `shotspec/1`:

| in the shotspec | meaning | whose |
| --- | --- | --- |
| `id` | `S-719_9u2pj` — the scene code and the shot's own stamp. Never its position. | board |
| `set`, `cast`, `off`, `props` | what is built and who is in frame; `off` are in the scene but never in frame | board |
| `withheld` | how much of Krishna this shot may show — `hands`, `shadow`, `offscreen` | board (story law) |
| `camera` | lens, height, angle, move, start and length; `src` and `duration_src` say `authored` or `derived` | board |
| `continuity` | previous shot, screen direction, time of day | board |
| `rev` | a fingerprint of all of the above | board |
| `view` (on the scene) | sequence, cut number — where it falls today | board, **and never to be used in a name** |
| `provenance` | board version, generator version, when | board |

## What flows back — a report

```json
{ "shot_id": "S-719_9u2pj", "app": "blender", "status": "rendered", "version": 2,
  "files": { "block": "renders/S-719_9u2pj_block_v002.png" },
  "shot_rev": "0k3x9a", "params": { "engine": "workbench" } }
```

Allowed: `shot_id`, `app`, `status`, `version`, `files`, `at`, `note`,
`params`, `shot_rev`, `board_version`, `generator_version`. **Anything else is
refused**, and if it is one of the board's fields (`camera`, `cast`, `set`,
`duration_s`…) the refusal says so and says where the change belongs. A report
file is taken whole or not at all.

`params` is the application's own craft — a seed, a checkpoint, a solver
setting — recorded so the result can be made again. It is never read back as
intent.

## Stale

Every report carries the `rev` of the shot it was made from. When the shot
changes on the board, the fingerprint changes, and the board shows that work as
**stale** at once. A guessed length moving because a neighbour's was set does
not count; a decision does.

## Per application

| | the board's (intent) | the application's (craft) | status |
| --- | --- | --- | --- |
| **After Effects** | shots, order, lengths, pictures, dialogue | the layout's look (`LOOK`) | built; reads the shotspec |
| **Blender** | set, cast, lens, height, length, who is hidden | nothing yet — blocking is fully generated. When animation starts: curves, poses, anything inside a shot's frame range that does not move its camera or length | built and tested headless |
| **ComfyUI** | the prompt, the control passes it must follow, the withheld rule | checkpoint, ControlNet, seed, steps, strength (all reported in `params`) | runner built; tested against a stand-in server, not a GPU |
| **Houdini** | which environment, which shots need a simulation | every solver and scatter parameter | not built — needs parameters on the set entities |
| **Nuke** | which renders, which shot, which version is current | the comp graph | not built — needs renders to comp |
| **Unreal** | sets, cameras, lengths | lighting, the level itself | not built — needs the assets to exist in Unreal |

## Adding an adapter

In `pipeline/dcc_bridge.py`, an adapter is a function that takes the bridge and
returns what it wrote and how to run it. It reads `bridge.spec` and nothing
else, writes into the project folder, and the application's results come back
through `bridge.report` or `bridge.ingest`. Replace the `not_built(...)` entry
in `ADAPTERS` and add its row above.

## The MCP server

```bash
python3 pipeline/dcc_bridge.py serve --project previz/S-719
```

Plain JSON-RPC over stdio, no dependencies. Tools: `shotspec_summary`,
`list_shots`, `get_shot`, `generate`, `report`, `ingest`, `status`. To add it
to Claude on your machine, register that command as a local MCP server.
