# Scoring the style test

Two seeds per cell exist so you can answer question 1. Answer it first.

| # | question | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- | --- |
| 1 | **Does it repeat?** Same recipe, two seeds — same medium, palette and line weight? | different medium | same medium, different look | close | indistinguishable in style |
| 2 | Does it match the reference frames? | no | roughly | close | yes |
| 3 | Right century and continent? Any Roman helmet, Greek column or pagoda is 0 | wrong | one slip | minor | clean |
| 4 | Did it obey the composition — distances, empty foreground, figure size? | no | partly | mostly | yes |
| 5 | Can it withhold? (a hand in frame, the figure out of shot) | draws a face anyway | sometimes | mostly | yes |

Add them up per model+recipe. The winner is the one with the highest **1**,
not the highest **2** — a slightly plainer look you can reproduce beats a
beautiful one you cannot.

Write the scores into this file under a heading per model so the next pass has
something to compare against.
